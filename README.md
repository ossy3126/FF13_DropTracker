# FF13 RTA ドロップトラッカー

ファイナルファンタジーXIII の RTA（リアルタイムアタック）中に、敵からドロップした**素材**と**戦闘アイテム**を記録し、売却額（GIL）の合計をリアルタイムで確認するための Web ツールです。
## 使い方

1. `index.html` をブラウザで開きます（PC・スマホどちらでも可）。
2. 上部のタブで **素材** / **戦闘アイテム** を切り替えます。
3. 章ボタン（`Ch.1` 〜）で現在の章を選ぶと、その章でドロップするアイテムのボタンが表示されます。
4. ドロップしたらアイテムのボタンをタップ → インベントリに追加されます（同じアイテムは個数が増えます）。
5. 画面下部のフッターに、素材・戦闘アイテム別の売却額と総合計が表示されます。

- インベントリはタブごとに 1 つで、章ごとには分かれていません。章を切り替えてもアイテムは残り、累積していきます。
- フッターは開いているタブに関係なく、常に両タブの合計を表示します。
- 記録はページを再読み込みしたり閉じたりするとリセットされます。

## 機能

### インベントリ（2 列グリッド）
- 初期状態で 6 枠。埋まると自動で枠が増えます。
- 各枠の `−` / `＋` で個数を調整。0 になると枠が空きます。
- 枠には「小計（単価）」が表示されます。
- **並べ替え**：枠をタップして選択（オレンジ枠）→ 別の枠をタップで入れ替え。PC ではドラッグ＆ドロップでも入れ替えられます。
- **手動割り当て**：空き枠をタップすると、そのタブの全アイテム一覧から選んで配置できます。

### 章ごとの特殊操作
| タブ | 章 | 機能 | 動作 |
|---|---|---|---|
| 素材 | Ch.7 | 素材全消去 | 素材の枠をすべてクリア（売却後のリセット用） |
| 戦闘アイテム | Ch.7 / 9 / 11 / 12 | 医術解体 | チェックで パワースモーク・バリアスモーク・エーテルスモーク・エリクサー を各 1 個追加。チェックを外すと各 1 個取り消し |

### 全リセット
右上の **全リセット** から、確認ダイアログを経て素材・戦闘アイテムのデータ、章選択、医術解体のチェックをすべて初期化します。

## 収録データ

- **素材**：Ch.1〜10（Ch.6 はドロップなし）
- **戦闘アイテム**：Ch.1〜13（Ch.8 はドロップなし）

売却単価は `index.html` 内の `DATA` オブジェクトで定義されています。

## データの編集

アイテムや単価を変更する場合は `<script>` 内の `DATA` を編集します。

```js
const DATA = {
  material: {
    maxCh: 10,                 // 章ボタンの数
    allMap: { '欠けた牙': 15 }, // 合計計算・手動割り当てに使う単価表
    chapters: {
      1: [{ name: '欠けた牙', price: 15 }] // 章ごとのドロップボタン
    }
  },
  battle: { /* 同様 */ }
};
```

> **注意**：合計 GIL の計算は `allMap` の単価を参照します。`chapters` にアイテムを追加したときは、`allMap` にも同じ名前で単価を登録してください。
